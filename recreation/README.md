# Recreation — clean-room layout study

This scaffold recreates **layout patterns** observed on a leather-goods storefront
(sticky dark header, hero, category tiles, 4-column product grid with hover-reveal
card, value props, newsletter band, dark footer, floating chat button, sticky cart bar).

Everything here is original: placeholder brand "Example Leather Co.", placeholder
copy written for this demo, CSS gradient placeholders instead of photography.
No copied markup, text, images, or branding from any real site.
